# College Lost and Found Management System

## About the Project
The College Lost and Found Management System is a console-based Java application developed to help students report lost belongings and register found items within the college campus.

The main objective is to make it easier to search for missing belongings and manage reported items.

## Features
- Report Lost Items
- Report Found Items
- Search Items by Name
- View All Lost Items
- View All Found Items
- Mark Items as Returned

## Technologies Used
- Programming Language: Java
- Application Type: Console-Based
- Data Storage: Arrays
- Input Handling: Scanner Class

## Core Java Concepts
- Classes and Objects
- Constructors
- Methods
- Arrays
- Static Variables and Methods
- String Handling
- Conditional Statements
- Loops
- Switch Statements

## How to Run

1. Install Java JDK.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Compile the program:

```bash
javac CollegeLostAndFoundSystem.java
```

5. Run the application:

```bash
java CollegeLostAndFoundSystem
```
